# AmneziaWG для UniFi Dream Router 7
Пошагово можно посмотреть в html на Github https://stebasha.github.io/UDR-Amnezia/
Туннель AmneziaWG прямо на UDR7, встроенный в штатные правила **Policy-Based Routes** UniFi: в туннель уходят только те устройства, сети и домены, которые вы выбрали в интерфейсе UniFi. По желанию: запасной канал на своём VPS с автопереключением, панель состояния при входе по SSH, аудит и уведомления в Telegram.

## Быстрая установка

На роутере по SSH под root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/stebasha/UDR-Amnezia/main/install.sh)
```

Мастер спросит сценарий, конфиги и опции, проверит каждый шаг и при ошибке предложит варианты. Повторный запуск открывает меню обслуживания:

```bash
/data/awg/install.sh            # меню: обновление, компоненты, диагностика, удаление
/data/awg/install.sh --update   # обновить скрипты из репозитория, конфиги сохраняются
/data/awg/install.sh --restore  # после обновления прошивки UniFi
/data/awg/install.sh --status   # панель состояния
/data/awg/install.sh --uninstall
```

## Сценарии

| | Что у вас есть | Что делает мастер |
|---|---|---|
| **A** | Конфиг AmneziaWG от VPN-провайдера | Поднимает туннель, подключает к PBR, ставит сторожа |
| **B** | Свой VPS (Ubuntu/Debian, root, белый IP) | Сам заходит на VPS по SSH, собирает и настраивает сервер AWG, забирает конфиг |
| **C** | Конфиг провайдера + свой VPS | Основной + запасной туннель, автопереключение за ~15 с, возврат через 10 минут стабильной работы |

Дополнительно: клиенты VPN-сервера роутера (WireGuard Server, Teleport) через туннель, панель `awgs`, аудит `awg-audit`, Telegram с суточным отчётом.

## Что мастер проверяет

- архитектуру (aarch64), UniFi OS, `/dev/net/tun`, нужные команды, место на `/data`, доступ к GitHub;
- остатки старых установок: обычный WireGuard `wgbackup`, тестовые правила, чужой установщик `/data/awg-native`, ручные экземпляры сторожа (предлагает убрать);
- бинарники AmneziaWG: что они запускаются на роутере;
- конфиг: секции, ключи, Address, Endpoint; предупреждает, если это обычный WireGuard без обфускации;
- туннель: внешний IP через интерфейс и handshake; при сбое — диагностика tcpdump на WAN, а для своего VPS одновременно на сервере, с выводом причины (порт у хостера, ключи, параметры обфускации, DPI);
- PBR: находит таблицу, метку и профиль VPN Client; если правила нет — генерирует фиктивный профиль-«рельсу» и показывает, что сделать в UniFi;
- сторожа: что маршрут появился в таблице PBR, вместе с `blackhole` (без утечки в WAN при падении туннелей);
- переключение на запасной канал (по желанию, имитацией сбоя);
- Telegram: токен через `getMe`, chat id автоматически, тестовое сообщение.

## Структура

```
install.sh          установщик и меню обслуживания
VERSION
awg/                файлы роутера → /data/awg
  up.sh               поднять туннели из main.conf / backup.conf
  failover.sh         сторож: таблица PBR, проверки, переключение
  awg-detect.sh       найти таблицу, метку, профиль PBR → awg.env
  status.sh           панель (awgs)
  audit.sh            аудит (awg-audit)
  notify.sh, awg-notify.sh   Telegram
  awg-restore.sh      восстановление после обновления прошивки
  awg-uninstall.sh    удаление
  *.service           юниты systemd (копии в /data/awg)
server/             файлы VPS
  awg-server-build.sh   сборка amneziawg-go и awg
  awg-server-setup.sh   ключи, обфускация, служба awg-server
  audit-server.sh       аудит VPS
index.html     подробный гайд с ручной установкой, диагностикой и справочником
```

## Что проверено

- **Вживую на UDR7** (UniFi OS 5.1.33, Network 10.6.106): схема целиком — основной туннель от провайдера с параметрами AWG 2.0, запасной до своего VPS (Ubuntu 24.04), PBR по доменам и адресам, клиенты VPN-сервера роутера, переключение и возврат, панель, аудит, уведомления.
- **На заглушках:** установщик и универсальные версии скриптов (сценарии A, B, C, ошибки конфигов, диагностика, повторное использование сервера, обновление, восстановление, удаление). На чужом роутере они ещё не запускались — сообщайте о проблемах.

## Безопасность

- Один конфиг AmneziaWG = одно устройство.
- Конфиги и токены не отправляются в чаты и тикеты; файлы с ключами получают права 600.
- Бинарники для роутера берутся из [AmneziaWG-Unifi-DreamMachine](https://github.com/DjGreeZ/AmneziaWG-Unifi-DreamMachine) (только `bin/`, его установщик не используется). Сборку из исходников см. в гайде.
- Изменения через CLI выходят за штатную работу устройства. `install.sh --uninstall` убирает всё, что поставил установщик.
